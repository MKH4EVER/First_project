# Sierra Store

A clean, Apple-inspired demo storefront with product browsing, cart interactions, and a lightweight checkout experience. Everything runs client-side so you can open the HTML locally.

## Features
- Announcement ribbon with promo link plus Apple-inspired shell, hero, and device highlight card.
- Product grid with category filters, search, and sorting; cards use subtle tones inspired by Apple hardware.
- Service highlights for delivery, returns, exclusives, and pickup in a calm banded panel.
- Bag controls for add/update/remove (including hero CTA), local persistence, and live order totals with free-shipping threshold.
- Accessible checkout form with confirmation toast and focus-visible styling.
- Responsive layout with sticky nav, soft shadows, and touch-friendly targets.

## Getting started
1. Open `index.html` in your browser (no build tools required).
2. Browse products, add them to the bag, and submit the checkout form to see the confirmation state.

## Customization
- Update the `products` array in `app.js` to change catalog data or accent gradients.
- Adjust color tokens and typography in `styles.css` to match your brand.
